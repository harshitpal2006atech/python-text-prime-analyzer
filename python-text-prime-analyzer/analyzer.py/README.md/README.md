# Text & Prime Analyzer

A simple Python command-line program that analyzes a sentence and checks whether a given number is prime.

## Features

The program:

* Counts the number of words in a sentence
* Finds the longest word
* Reverses the sentence
* Checks whether a number is prime
* Uses separate functions for each task
* Takes input directly from the user

## Requirements

* Python 3.x
* No external libraries are required.

## How to Run

1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Run:

```bash
python analyzer.py
```

On some systems, you may need:

```bash
python3 analyzer.py
```

## Example

```text
=== Text & Prime Analyzer ===
Enter a sentence: Python is easy to learn
Enter a number: 17

--- Results ---
Word Count       : 5
Longest Word     : Python
Reversed Sentence: nrael ot ysae si nohtyP
Prime Check      : 17 is a prime number.
```
